# The Mind of Nox

An [Eleventy](https://www.11ty.dev/) site. Content is written directly in `src/www/`.

## Workflow

```sh
npm run serve    # local preview at http://127.0.0.1:8099
npm run build    # production build into _site/
npm run dev      # netlify dev
npm run publish  # build, commit and push (Netlify deploys from master)
```
